# AI Stock Market Intelligence & Forecasting

An interactive machine-learning project for stock market analysis,
technical indicators, historical price visualization, and experimental
24-step stock price forecasting.

## Features

- Stock search using ticker symbols
- Historical high, low, close, and volume charts
- Candlestick visualization
- RSI, MACD, SMA, EMA, and Bollinger Bands
- Random Forest, Extra Trees, and Gradient Boosting models
- Model comparison using MAE, RMSE, and directional accuracy
- Experimental recursive price forecast
- Beginner-friendly stock market explanations
- Downloadable CSV reports

## Technologies

- Python
- Streamlit
- Pandas and NumPy
- Scikit-learn
- Plotly
- Yahoo Finance data through yfinance

## Run the Project

Install dependencies:

pip install -r requirements.txt

Start the application:

streamlit run app.py

## Important Disclaimer

This project is intended for educational purposes.
Predictions are estimates and do not guarantee future prices.
Market data availability and delays may vary.
